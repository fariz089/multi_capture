Multi-Capture Cookie Bridge

Login ke platform target di tab Chrome biasa (bukan tab popup ini). Pilih platform di bawah → cookies + localStorage di-extract → kirim ke multi_capture local server untuk review/push ke SocialPulse.

Bagaimana cara pakai
  1. Buka tab Chrome → login ke Facebook / Instagram / TikTok / Twitter / Threads seperti biasa
  2. Pastikan multi_capture jalan di laptop (port default 5099)
  3. Buka extension ini, isi label akun
  4. Klik tombol platform yang sama dengan tab login kamu
  5. Status akan muncul. Cek GUI multi_capture untuk Push ke SocialPulse.
